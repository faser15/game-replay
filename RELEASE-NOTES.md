# GameReplay 1.3 desktop preview

## Added

- Selected-window capture and GPU resizing on the tested Windows/NVIDIA path.
- Configurable replay duration, quality, audio, storage folder, and quota.
- Full sessions, bookmarks, screenshots, custom hotkeys, opt-in voice saving, and executable-based game profiles.
- Microphone mixing/separate tracks, gain, denoise, and optional webcam overlay.
- Local clip library with search, sorting, favorites, tags/albums, imports, and recycling.
- Trim, crop, speed, volume, captions, soundtrack, watermark, MP4/GIF export, and audio-preserving merge.
- Self-contained Windows executable with checksum-verified first-run engine setup.

This is a desktop preview, not complete Medal parity. Native game hooks, per-game automatic kill/win integrations, per-application audio isolation, a full multitrack timeline, and cloud/social/mobile features remain outside the release. Device-dependent microphone/webcam/voice paths need testing on the user's hardware.

Default quality stays 720p/30 FPS/3 Mbps. Full sessions and edits are bounded by storage controls; temporary operations may briefly need additional space. See README and the feature checklist for limitations.
