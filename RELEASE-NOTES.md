# GameReplay 1.3.1 — Readable settings and app branding

- Keep recording settings and hotkey labels readable while recording. Previously disabling the entire tab caused Windows to draw dark disabled text on the dark background.
- Settings can be reviewed while recording; applying changes still requires recording to stop.
- Add an original GameReplay icon to the executable, window, tray and header.
- Replace the default white tab strip with navigation styled for the dark interface.

Exit the previous GameReplay from its tray menu before opening this version. Existing clips and settings remain in the same location.

This updates the desktop preview. Remaining feature gaps are listed in FeatureInventory.md.
